# 公网访问配置指南（Cloudflare 快速隧道）

> 适用于 小笑肖 v4.0.2 · 手机不在家里 Wi-Fi 时怎么连上电脑后端

---

## 结论先说

**用启动器里那个「生成公网地址」勾选框，其他都不用管。**

勾上 → 几秒后界面上出现一个 `https://xxx-xxx-xxx.trycloudflare.com` 地址 → 复制 → 填到手机里。

不用注册账号、不用买域名、不用备案、不用改任何穿透软件。

---

## 为什么放弃 SakuraFrp

不是配置问题，是这条路本身走不通。三条都实测过：

| 尝试 | 实测结果 | 原因 |
|---|---|---|
| 内地节点 + TCP + 明文 HTTP | **501** | 节点页面写明「执行机房的内容合规要求」，拒绝明文 HTTP |
| 同上，改用 HTTPS | **握手即断**（read 0 bytes） | TCP 隧道不做 TLS 终结，节点没有证书 |
| 换台湾节点（36.235.161.125） | **Empty reply**，后端零请求 | 节点能连上，但流量没转到本机（四个候选端口全空） |
| HTTP 类型隧道 + 自动 HTTPS | 未尝试 | 需要绑定域名，内地建站节点还要求域名已备案 |

Sakura 官方文档自己也写着：

> 使用 `TCP` 隧道时，如果穿透的**应用协议是 HTTP，必须使用非内地节点**

而换到非内地节点之后，流量又转不下来。继续在它身上耗没有意义。

## Cloudflare 快速隧道为什么能用

| 特点 | 说明 |
|---|---|
| 不用账号 | 匿名即可创建，Cloudflare 自己写在启动横幅里 |
| 不用域名 | 自动分配 `*.trycloudflare.com` 子域 |
| 自动 HTTPS | 真证书，手机端不会有任何安全警告 |
| 回源用明文 | Cloudflare 边缘终结 TLS，回源到本机是 HTTP —— 正好绕开「内地服务器不许跑明文 HTTP」那类限制 |
| 不限流量 | 免费且无月流量上限（个人使用完全够） |
| 出站即可 | 不需要公网 IP、不需要路由器端口映射 |

**唯一的代价**：地址是随机生成的，隧道重建一次就换一次。所以界面上给了「复制」按钮。

## 操作步骤

### 电脑端

1. 打开 **小笑肖-启动器.exe**
2. 确认「● 运行中」（没运行就点「启动服务」）
3. 勾选 **「生成公网地址（手机不在同一 Wi-Fi 时勾上）」**
4. 等 5–15 秒，地址栏出现 `https://xxx-xxx-xxx.trycloudflare.com`，变绿
5. 点右边的 **复制**

### 手机端

6. 打开小笑肖 App →「连接电脑」
7. 粘贴刚才复制的地址 —— **必须带 `https://`**
8. 点「连接电脑」

**注意**：地址栏里是 `https://` 开头，别手动改成 http。Cloudflare 只认真证书那条路。

## 自检清单

- [ ] 启动器显示「● 运行中」
- [ ] 公网地址那一行是**绿色**的 `https://...trycloudflare.com`
- [ ] 手机填的地址带 `https://`
- [ ] 手机和电脑**不需要**在同一 Wi-Fi（这正是它的用途）

想在电脑上先验证一下，把地址粘到浏览器打开 `/api/ping`，应看到：

```json
{"ok": true, "v": "4.0.2"}
```

## 地址为什么会变

快速隧道是匿名的，Cloudflare 不保留你的子域名。每次重建隧道（关掉启动器再开、换网络）都会得到一个新地址。

**这意味着**：每次重启后，手机里那个地址要更新一次。

想固定地址有两条路（都属于以后有域名时再说）：

1. 注册 Cloudflare 账号，建**命名隧道**并绑定自己的域名 → 地址永久固定
2. 买个便宜域名托管到 Cloudflare，用命名隧道

现在这个阶段不值得为它花钱，先用随机地址。

## 安全说明（重要）

这个地址是**公开在互联网上**的。别人扫到也能打开页面。

防护分两层：

**第一层 · 页面能开，数据拿不到**

所有 `/api/*` 数据接口都要 `X-Pair-Key` 请求头（就是你手机里那把 36 位私钥）。
没有私钥的人打开页面，看到的是空壳 —— 页面能加载，但一条数据都读不出来。

实测：公网 `POST /api/query` 无 key → **401**。

**第二层 · 私钥不能被外人取走**

电脑端有个 `/api/session` 接口，是给「工作台窗口」自己取私钥用的（工作台页面在 pywebview 里跑，拿不到手机那份私钥）。

它靠「只允许本机访问」保护。但内网穿透会让所有外部请求看起来都来自 `127.0.0.1` —— 这个保护会失效。

**已修复**：现在除了检查源 IP，还会检查请求里有没有反向代理留下的转发头（`CF-Connecting-IP`、`X-Forwarded-For` 等）。只要带了这类头，一律当外部请求，返回 **403**。

实测：公网 `GET /api/session` → **403 forbidden**；本机直连 → 正常。

**所以**：
- 私钥不要外传
- 不用的把勾去掉，隧道就断了

## 已知限制

1. **需要电脑开着、启动器开着** —— 电脑关机/启动器关掉，手机就连不上。这是「以电脑为服务器」的固有代价。
2. **地址每次变** —— 见上面那节。
3. **Cloudflare 免费隧道不保证 SLA** —— 它自己在启动日志里写了 "no uptime guarantee"。个人日常够用，别当生产环境。
4. **国内访问 `trycloudflare.com` 偶尔会慢** —— 实测首次连接 1.5 秒左右，后续正常。

---

## 备用：局域网直连

手机和电脑在**同一个 Wi-Fi** 时，不需要公网地址：

- 启动器上「局域网地址」那一行（形如 `192.168.1.37:8731`）
- 手机直接填这个，**不用带 http://**
- 那个勾选框可以取消

局域网比走公网快得多，在家优先用这个。
