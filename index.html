小笑肖 · 在线生活工作台

一个自托管、双端同步的本地生活工作台 · 数据存你自己的设备，不依赖任何第三方云服务

把「今日概览 / 记账理财 / 习惯健康 / 减脂健身 / 日程统筹 / 待买清单 / 书影音收藏」七大模块收进一个 App。 电脑端就是服务器，手机按需连上来同步；每台设备一把私钥守门，没配对不给写。

快速上手

电脑端网页界面

打开 server/_web/index.html 预览工作台

下载安卓 APK

android/xiaoxiaoxiao-4.0.2.apk（已构建）

自行构建安卓端

cd android && bash build.sh（需 JDK21 + build-tools）

启动同步后端

python server/server.py 起本地服务

本地预览（电脑端）

cd server
pip install -r requirements.txt
python server.py
# 浏览器打开提示的本地地址

设计要点

  • 本地优先：断网照常记录，联网后自动补推离线队列。
  • 双端同步：手机 ↔ 电脑，增量拉取，每条记录带 source（pc / phone）互不覆盖。
  • 私钥鉴权：X-Pair-Key 头校验，私钥永不上网，仅首次配对时算一次哈希存本机。
  • 可迁移：电脑地址可改；即开即用、即关即停，不常驻系统服务。
